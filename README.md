🛒 Customer Shopping Behaviour Analysis

A Data Analytics Project using Python, SQL & Power BI

📌 Overview

This project analyzes customer shopping behaviour to uncover patterns, trends, and insights that support better business decisions.
It covers the full analytics workflow—from loading and cleaning data in Python, running SQL queries, building interactive Power BI dashboards, and presenting insights through a final report.

📂 Dataset

The dataset contains information such as:

Customer demographics

Product categories

Purchase amounts

Shopping behaviour & preferences

It was cleaned and prepared in Python before deeper SQL and BI analysis.

🛠 Tools & Technologies

Python (Pandas, NumPy, Matplotlib/Seaborn)

SQL (PostgreSQL / MySQL / SQL Server)

Power BI (interactive dashboards)

Gamma.app (final presentation)

Jupyter Notebook

📉 Project Steps
1. Load & Inspect Data (Python)

Imported dataset with Pandas

Reviewed structure, missing values, and inconsistencies

2. Exploratory Data Analysis (EDA)

Summary statistics

Visualisations to explore trends

Identified behavioural drivers

3. Data Cleaning

Removed duplicates

Filled or handled missing values

Standardised formatting

Prepared dataset for SQL and BI

4. SQL Analysis

Executed SQL queries to answer stakeholder questions, including:

Top customers and segments

Most profitable product categories

Purchase frequency patterns

Trends in customer behaviour

5. Power BI Dashboard

Interactive dashboard featuring:

Revenue & sales trends

Customer segments

Product category insights

Behaviour and frequency patterns

6. Final Report & Presentation

Findings summarised in a structured report

Gamma presentation explaining process, insights & recommendations

📊 Dashboards

The Power BI Dashboard (Customer_Behaviour_Dashboard.pbix) includes pages for:

Overview

Key metrics and KPIs

✅ Results & Insights

Key takeaways include:

Identification of high-value customer groups

Product categories driving most revenue

Behavioural trends that support marketing decisions

Recommendations for improving profitability and customer satisfaction
